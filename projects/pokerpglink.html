PokeRPGLink

A touch panel for the AYN Thor's bottom screen that plugs into Pokémon fangames running on the top one: battle menus, your party, the bag, the map and the Pokédex, all one tap away — without ever stealing the controller from the game.

Source on GitHub → Download the APK active

// the idea

The Thor has two screens, and RPG Maker fangames only use one. PokeRPGLink turns the second one into the DS-style touch screen these games never had. A small mod inside the game reports what's happening; the Android app draws it on the bottom screen and sends your taps back as commands. The panel's window can't take focus, so the top screen keeps the controller the whole time.

// what it does

  • Battles on the bottom screen Fight, Bag, Pokémon and Run as big buttons; moves with type, power, PP and effectiveness against each foe; target picking in double battles; a quick-throw button for the last Poké Ball you used.
  • Out of battle The wild Pokémon in the current area (shadows until caught, day/night icons), party summaries with move reordering and held items, a usable bag, saving, the town map with fly, and a full Pokédex.
  • Several games, one panel Pokémon Rejuvenation, Reborn, Desolation, Infinite Fusion and Pokémon Tectonic — each with its own mechanics shown properly: Rejuvenation's field effects, Shadow Pokémon and boss shields, Tectonic's Avatars and statuses.
  • Sets itself up The app finds the games on the device, installs the mod into the right place (even into Tectonic's compiled plugin file) and keeps it updated.
  • Skins and plugins Ten built-in skins, from a bouncy BDSP-style look to a 16-bit console theme, remembered per game. Anyone can make their own with CSS and JavaScript, including animations and sounds that react to battle events.

// how it's built

A Ruby mod hooks the game's battle and map scenes and writes the game state to a small JSON file several times a second. The Android app (Java) shows a WebView UI in a non-focusable overlay on the second display and writes one file per tap, which the mod turns into the game's own menu inputs. Adapters cover the different engine families, and every hook fails on its own, so a game update turns off one feature instead of breaking the game.
