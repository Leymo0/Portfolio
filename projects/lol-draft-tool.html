League Lobby Draft Tool

A custom draft randomizer for private lobbies, built to make normal games feel like a challenge run — with tiered champion pools and forced item builds.

rebuilt twice, still tinkering

// the idea

Normal draft in a private lobby gets stale fast. Instead of picking freely, this tool rolls each player a champion from a tiered pool — and locks in a mandatory item build alongside it — so every game forces a different playstyle instead of everyone reaching for the same handful of champions.

// how it works

  • Three difficulty tiers Safe — solid, straightforward champions. Spicy — off-meta but playable. Chaos — pure comedy picks that force you to improvise.
  • Mandatory item assignments per roll Each roll comes with a required build path, not just a champion — so the challenge isn't only "what do I play," it's "how do I make this work."
  • Two full rebuilds Went through it twice from scratch as the tiering logic and roll rules got refined based on what actually made games fun versus just chaotic.
